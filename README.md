# Statio

A personal macOS menu bar monitor with a clean, customizable layout.

[Download the latest release](https://github.com/justaicode/statio/releases/latest)

Statio shows CPU, memory, network and disk activity. Choose item order, spacing, icons, labels and graphs, hide the Statio gauge, and optionally show the country of your public internet connection.

## Updates

Open **Statio Settings → General → App Updates** to check for updates or enable automatic download and installation. Release feeds and downloads are signed with Statio's update key and verified by the app.

The first hosted build is **0.2.1**. Older local builds without a configured update source need this version installed once before in-app updates work.

## Requirements

Apple silicon Mac, macOS 14 or newer. This personal edition is locally signed and is not Apple-notarized.

## Privacy

System readings and layout preferences stay on the Mac. There are no accounts or analytics. The optional country flag contacts country.is, with ipwho.is as a backup, to look up the country of the public connection. Update checks and downloads contact GitHub.

This repository hosts release downloads and their signed update feed.
